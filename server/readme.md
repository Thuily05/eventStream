\### Ý nghĩa câu lệnh



\* `npm init -y`: Lệnh này tạo nhanh một file `package.json` với các thiết lập mặc định (với `-y` nghĩa là "Yes" cho tất cả các câu hỏi cấu hình ban đầu). File này đóng vai trò như một "sổ tay" quản lý thông tin dự án và danh sách các thư viện đi kèm.

\* `npm install express`: Lệnh tải duy nhất thư viện Express và các phần phụ thuộc của nó từ Internet về máy.

\* Yêu cầu cài sẵn Node.js: Chính xác! Máy tính của bạn bắt buộc phải cài đặt sẵn Node.js thì mới có thể sử dụng được lệnh `node` (để chạy file) và lệnh `npm` (để tải thư viện).
